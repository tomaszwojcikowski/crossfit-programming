# Tuesday (22/09/2026)

**Setup**

- **Equipment**: pull-up rig
- **Timing**: 60-min class cap; 8' EMOM + 8' EMOM + 8' AMRAP (~24 min main)
- **Stimulus**: strict pulling skill, then kipping density into a short gymnastics triplet AMRAP
- **Scaling A**: banded strict pull/chin; T2B → hanging knee raises; elevate push-ups
- **Scaling B**: ring rows (supinated for chin-ups); V-ups; knee push-ups
- **Logistics**: assign rig lanes; brief strict vs kipping standards before each block
- **Top Cues**:
  - **Strict pull-up / chin-up**: “Chest up, pull the bar down.”
  - **T2B**: “Short sets, kick through.”
  - **Push-up**: “Chest to deck, lock out.”

## Warmup (15 min)

**Flow**

- **Before 0:00**: bands hung on every rig bar; mats laid behind each bar; max 3 athletes per bar
- **Groups**: rig lanes of 3 (number off 1-2-3); same lanes for the whole class
- **Clock**: running clock; coach calls "Switch" for every station change

- **R1 RAISE (0:00-3:30, easy)**: lines across the floor, coach sends waves:
  - 2 lengths easy jog
  - 1 length skip with arm circles
  - 1 length bear crawl
  - 4 inchworm walkouts to a push-up position
- **R2 ACTIVATE (3:30-9:00, moderate)**: 3-station lane rotation, 30s each; 3 full rotations:
  - **Bar**: 5 scap pulls + 5 kip swings
  - **Floor 1**: 6 push-ups (or elevate) + 6 band pull-aparts
  - **Floor 2**: 8 hollow rocks
- **R3 POTENTIATE (9:00-13:00, hard)**: same rotation, 20s each; 3 full rotations:
  - **Bar**: 2 strict pull-ups or 2 strict chin-ups (alternate each turn; band if needed)
  - **Floor 1**: 5 fast push-ups
  - **Floor 2**: 15s hollow hold
- **Transition (13:00-15:00)**: pick EMOM band; set lane start order — athlete 1 starts at :00, athlete 2 at :20, athlete 3 at :40, so everyone gets a full minute on a shared bar
