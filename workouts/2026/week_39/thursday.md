# Thursday (24/09/2026)

**Setup**

- **Equipment**: barbell (thrusters 40/25), landmine or heavy DB/KB for rows, rower, KBs 24/16, mats
- **Timing**: 60-min class cap; 8× 1:45 on / 1:15 off (~24 min)
- **Stimulus**: rotating station AMRAPs — keep moving inside the work window, reset on the off
- **Scaling A**: thrusters 30/20; lighter landmine/DB rows; KB 20/12; elevate push-ups; tuck-ups
- **Scaling B**: DB thrusters; band/DB rows; single KB push press + goblet squat; sit-ups
- **Logistics**: set four stations (a–d); athletes rotate in order each work window; brief “score = total rounds+reps across all windows”
- **Top Cues**:
  - **Thruster**: “Hips through, punch up.”
  - **Landmine row**: “Chest tall, pull to the hip.”
  - **KB push press**: “Dip straight, lock out.”

## Warmup (15 min)

**Flow**

- **Before 0:00**: all four stations (a-d) built with loads for every athlete; split the class evenly — that's each athlete's starting station
- **Groups**: station groups of 3-4; stay together through the warmup rotation
- **Clock**: running clock; warmup rotation runs a → b → c → d, the same direction as the workout

- **R1 RAISE (0:00-3:30, easy)**: lines across the floor, coach sends waves:
  - 2 lengths easy jog
  - 1 length high knees + 1 length lateral shuffle each way
  - 1 length walking lunge with arm circles
- **R2 ACTIVATE (3:30-9:00, moderate)**: rehearsal rotation — 1:00 at each station, light, 15s to move on the "Rotate" call:
  - **a**: 6 PVC thrusters + 6 light DB rows
  - **b**: 30s easy row + 5 push-ups (share rowers: one rows while one does push-ups, swap)
  - **c**: 5 light KB push press + 5 goblet squats
  - **d**: 6 reverse lunges + 6 V-ups / tuck-ups
- **R3 POTENTIATE (9:00-13:00, hard)**: whole group back to the centre, no equipment; 3 rounds:
  - 4 jump squats
  - 4 fast push-ups
  - 4 V-ups
  - 10s fast feet
- **Transition (13:00-15:00)**: walk to your starting station and set workout loads; coach recaps a → b → c → d and "1:15 off = move and set up"

## Post-Warmup Mobility (60-90s)

- 30-45s front rack / shoulder opener
- 30-45s hip opener each side

## Movement Prep

At your starting station only (~2 min) — every station was already rehearsed in the warmup rotation:

- 2-3 reps of each movement at workout load
- Confirm the rep target and where you move next

## Main Conditioning

### 8 Rounds — 1:45 ON / 1:15 OFF

Rotate stations each work window (a → b → c → d → a → b → c → d):

**a) AMRAP**

- 10 **Thrusters** (40/25 kg)
- 20 **Landmine Rows** (heavy; 10/side if alternating)

**b) AMRAP**

- 12/10 **Cal Row**
- 10 **Push-Ups**

**c) AMRAP**

- 12 **Push Press** (2×KB 24/16)
- 8 **Front Squats** (2×KB 24/16)

**d) AMRAP**

- 12 **Reverse Lunges**
- 12 **V-Ups**

**Target**: keep moving the full 1:45; use the 1:15 to transition and breathe. Log rounds+reps per station.

**Expected**: ~2 full cycles of a–d; strong athletes bank partial third-cycle feel on early stations.

**Scaling options**

- **Scaling A**: thrusters 30/20, lighter rows, KB 20/12, elevate push-ups, tuck-ups
- **Scaling B**: DB thrusters, band/DB rows, single-KB options, sit-ups

## Cooldown & Debrief

- 2:00 easy walk + breathing
- 30-45s pec stretch each side
- Debrief: odd windows aren’t a sprint — consistent 1:45 efforts beat early redlines
