# Monday (10/08/2026)

**Setup**

- **Equipment**: rack + barbell + plates (back squat + Macho Man complex)
- **Timing**: 60-min class cap; back squat ~14 min (E2MOM × 7); Macho Man 15' EMOM
- **Stimulus**: heavy squat percentage wave, then unbroken clean–squat–jerk density under a fixed clock
- **Scaling A**: squat by feel at RPE 7-8; Macho Man 50/30 or hang power clean + front squat + push jerk
- **Scaling B**: goblet squat wave; DB clean + front squat + push press (3+3+3)
- **Logistics**: pair by rack for squats; strip to Macho Man load in the reset; brief “finish inside the minute” before the EMOM
- **Top Cues**:
  - **Back squat**: “Drive the floor away.”
  - **Power clean**: “Jump, then punch the elbows.”
  - **Jerk**: “Dip straight, punch up.”

## Warmup (8-10 min)

- **R1 RAISE (2:00 easy)**: 2:00 easy bike/row + nasal breathing
- **R2 ACTIVATE (1:30 moderate)**: 2 rounds:
  - 6 air squats
  - 6 empty-bar muscle cleans
  - 6 empty-bar front squats
- **R3 POTENTIATE (1:00 hard)**: 2 rounds:
  - 4 jump squats
  - 3 hang power cleans
  - 2 push jerks

## Post-Warmup Mobility (60-90s)

- 30-45s ankle rocks each side
- 30-45s front rack stretch

## Strength / Skill

### A) Back Squat — Every 2:00 for 7 Sets

Build through:

- 8×75%
- 7×78%
- 6×81%
- 5×85%
- 3×87%
- 3×87%
- 2×90%

**Target**: finish each set with ~30-60s to re-rack and reset before the next 2:00.

## Reset Window

2-3 min to set Macho Man load (60/35) and clear floor lanes.

## Movement Prep

1-2 crisp complexes, empty → workout load:

- 3 power cleans + 3 front squats + 3 jerks

## Main Conditioning

### B) Macho Man — 15' EMOM

Each minute:

- 3 **Power Cleans** (60/35 kg)
- 3 **Front Squats**
- 3 **Jerks**

**Target**: finish the complex in ~30-45s with 15-30s rest before the next beep. Drop load if you cannot finish inside the minute.

**Scaling options**

- **Scaling A**: 50/30; hang power clean + front squat + push jerk
- **Scaling B**: DB clean + front squat + push press (3+3+3)

## Cooldown & Debrief

- 1:00 easy walk + breathing
- 30-45s couch stretch each side
- Quick debrief: squat depth first; Macho Man only counts if every jerk locks out
